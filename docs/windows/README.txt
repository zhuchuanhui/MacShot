MacShot for Windows x64

Extract this ZIP to a folder, then run MacShot.exe. Keep the DLL files beside
MacShot.exe; they are required by the Windows build.

Screenshots and recordings are saved under Pictures\MacShot by default.
Recording resolution, quality, audio options, and estimated file sizes are
available in Settings.

For microphone recording, allow desktop apps to use the microphone in Windows
Privacy & security settings. System audio recording uses the default playback
device.

The bundled third-party runtime licenses and source links are in this folder.
