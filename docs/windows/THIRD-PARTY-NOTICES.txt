Bundled Windows runtime libraries
=================================

  GCC 13.1.0 runtime libraries. Distributed under GPL-3.0-or-later with the
  GCC Runtime Library Exception, version 3.1. License texts are included in
  COPYING3 and COPYING.RUNTIME.
  Corresponding source: https://gcc.gnu.org/pub/gcc/releases/gcc-13.1.0/gcc-13.1.0.tar.xz

libwinpthread-1.dll
  winpthreads from mingw-w64 11.0.0. Its MIT license is included in
  WINPTHREADS-COPYING.
