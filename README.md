# MacShot 0.6.0

MacShotは、スクリーンショットの撮影・編集・比較と、GIF／MP4の画面録画を行うアプリです。撮影したPNG/JPEGと録画を一覧から確認できます。

## ダウンロード

- macOS Apple Silicon (arm64): [MacShot-v0.6.0-macos-arm64.zip](https://github.com/zhuchuanhui/MacShot/releases/download/v0.6.0/MacShot-v0.6.0-macos-arm64.zip)
- Windows x64: [MacShot-v0.6.0-windows-x64.zip](https://github.com/zhuchuanhui/MacShot/releases/download/v0.6.0/MacShot-v0.6.0-windows-x64.zip)
- [GitHub Releaseページ](https://github.com/zhuchuanhui/MacShot/releases/tag/v0.6.0)
- 各ZIPのSHA-256: Release添付のチェックサムファイルを参照してください。

macOS版はZIPを展開して `MacShot.app` をアプリケーションフォルダへ移動すると、以後起動しやすくなります。マイク権限の付与自体にアプリケーションフォルダへの移動は必要ありません。署名済みですが、公証はしていません。初回起動時に開けない場合はFinderでアプリをControlキーを押しながらクリックし、「開く」を選んでください。macOS 14以降のApple Siliconに対応します。

Windows版はZIPを展開して `MacShot.exe` を起動してください。ZIPには起動に必要なWindowsランタイムDLLも含まれます。MP4録画ではWindowsの既定の再生デバイス音声と既定のマイクを収録します。マイクが入らない場合はWindowsの「設定 > プライバシーとセキュリティ > マイク」でデスクトップアプリのアクセスを許可してください。

## 使い方

### スクリーンショット

1. 「撮影・編集」で撮影対象を選びます。アクティブウィンドウ、メイン画面、全画面、個別画面、一覧にあるウィンドウを指定できます。
2. 「撮影してプレビュー」を押すか、撮影ショートカット（初期設定: `⌥`+`⇧`+`S`）を使います。範囲撮影は「範囲を選択」を押し、画面上をドラッグします。
3. 撮影画像は「証跡一覧」に保存されます。撮影日時と連番はファイル名に入り、設定を有効にすると画像内にも表示されます。

### 連続撮影

1. 「連続撮影を開始」を押します。MacShotのウィンドウが隠れます。
2. 撮影ショートカットを押すたびに、選択中の対象を撮影して順番に保存します。macOSではメニューバーに「撮影中」または保存枚数（例: `✓3`）が表示されます。
3. メニューバー／通知領域メニューの「連続撮影モードを開始／終了」で停止します。保存待ちの撮影が終わるとウィンドウが戻ります。「MacShotを開く」から先にウィンドウを表示することもできます。

### 画面録画

1. 「設定」で保存形式をGIFまたはMP4（H.264）にします。録画解像度は元の画面サイズ、480p、720p、1080p、2K（1440p）、4K（2160p）から選べます。GIFは色の再現とフレームレート、MP4はビットレートとフレームレートを個別に調整できます。調整欄の下に1分録画あたりの予想サイズが表示されます。MP4は設定ビットレートと音声から計算し、GIFは画面の動きや色で変わるため幅を持たせた概算です。
2. 「録画」を押すか、録画ショートカット（初期設定: `⌥`+`⇧`+`R`）を使います。録画中はメニューバー／通知領域に録画時間が表示されます。
3. メニューバー／通知領域メニューの「録画開始／停止」または同じショートカットで停止します。保存後、「証跡一覧」の録画一覧から「アプリ内再生」でGIF／MP4の映像を再生・一時停止できます。「ファイルを開く」ではMP4の音声も含めて再生できます。

MP4はシステム音声を録音します。マイクが許可されている場合はマイク音声も含みます。マイクを許可していない場合、MacShotはマイクへのアクセスを求めず、システム音声のみで録画します。GIFは音声なしです。

### 編集と画像比較

「証跡一覧」で画像の「連続編集を開始」を押すと、固定された一覧順に「前へ」「次へ」で移動しながら、赤枠・矢印・切り出しを追加できます。編集内容は元画像を残したままPNGとして保存できます。「画像比較」では2枚のPNG/JPEGを読み込み、左右・重ね合わせ・差分で比べられます。

## 権限

設定画面の「権限とデバイス」で、画面収録・システム音声とマイクの状態を個別に確認し、「権限状態を更新」で再確認できます。macOSでは「マイク入力をテスト（5秒）」で入力レベルを確認できます。テスト中に話すと、周囲の環境音と区別して入力を判定します。macOSでは起動中アプリの版と場所も表示するため、複数コピーがある場合にどのMacShotを確認しているか判別できます。

macOSで画面撮影が許可されていない場合は「画面・音声の設定を開く」を押して、システム設定でMacShotを許可します。アプリを「画面収録とシステムオーディオ録音」に追加する必要がある場合は、「FinderでMacShotを表示」からMacShot.appを見つけて設定画面へドラッグするか、「＋」から選択してください。権限を変更したらMacShotを終了して再起動します。

macOSのマイク設定にはアプリを手動追加する「＋」ボタンがありません。MacShotの「権限とデバイス」で状態を更新し、「macOSに許可を確認」を押すとmacOSの確認画面が表示されます。そこで許可するとMacShotが一覧に登録されます。確認画面が出ない場合は一覧へ手動追加できません。アプリケーションフォルダへの移動だけでも権限は付与されません。画面収録の一覧にある「＋」はマイク許可には使えません。マイクが拒否または未許可でも、MP4はマイクへのアクセスを求めずシステム音声のみで録画します。Windowsでは既定マイクの検出結果を表示し、マイクのプライバシー設定を開けます。Windowsのデスクトップアプリ権限はOS設定で確認してください。

## 表示の調整

設定の「表示量」でコンパクト・標準・ゆったりを選び、画面内に表示する情報量を調整できます。「文字サイズ」は−5%／＋5%ボタン、80／100／120／140%の直接選択、またはスライダーで80〜140%に調整できます。変更は次回起動後も保持されます。

設定カードの「カード配置を調整」を押すと、カードごとに上下の順番、半幅／全幅、余白サイズを選べます。「保存して固定」で確定し、「キャンセル」では調整前に戻します。初期配置は、録画・撮影・ショートカット・権限を半幅で並べ、表示カードを下部に全幅で配置します。

## 対応形式

- MacShot独自の画面録画: GIF、MP4（H.264）
- 撮影済み画像の読み込み・編集・比較: PNG、JPEG
- 録画一覧でのプレビュー: GIF／MP4の映像をアプリ内で再生・一時停止できます。GIFはファイルの繰り返し設定に従います。MP4はAAC音声トラックの有無も表示します。アプリ内再生では音声を再生しません。MP4の音声を聴く場合は「ファイルを開く」で標準の再生アプリを開きます。
- macOS標準の撮影・録画パネル: macOS側の機能として開きます。MacShot独自の録画形式設定とは別です。

macOSでは「macOS標準の撮影・録画」から標準スクリーンショットパネルを直接開けます。画面全体・ウィンドウ・範囲の撮影と録画、タイマー、マイク、ポインタ／クリック表示、保存先、フローティングサムネールはmacOSの標準パネルで設定できます。MacShot独自の録画ボタンでは設定画面のGIF／MP4形式を使います。

## 開発

```sh
cargo run
cargo build --release
```

macOSアプリを配布する前に、権限説明文と署名を検証してください。

```sh
scripts/verify_macos_bundle.sh output/MacShot.app
```

macOS版はmacOS 14以降のApple Siliconに対応します。macOSで画面撮影・録画を使うには、システム設定の「画面収録とシステムオーディオ録音」でMacShotを許可してください。権限を変更した後はMacShotを再起動します。Windows x64版は `output/Windows/MacShot.exe` にあります。

Windows上ではRustを用意したうえで `cargo build --release` を実行してください。Windows x64の実行ファイルはこのMacからGNUターゲットでクロスビルド済みですが、Windows上での起動確認は未実施です。
